# Tedrick Holmes Author Site

A responsive React + Vite author website.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Build for production

```bash
npm run build
```

## Customize

- Replace the portrait placeholder in `src/App.jsx` with your author photo.
- Update book details in `src/data/books.js`.
- Add your real social links in `src/App.jsx`.
- Connect the newsletter and contact forms to Resend, Formspree, ConvertKit, Mailchimp, or another service.
- Replace journal placeholders with real posts or connect a CMS such as Sanity, Contentful, or WordPress.
